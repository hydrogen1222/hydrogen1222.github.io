# Examples

以下示例用于说明“从提纲式笔记到博客式科研笔记”的转换原则。内容仅为风格演示，不应被当作具体体系的科学结论来源。

---

## 示例 1：不要把因果链拆成 bullet

### 原始笔记

```markdown
## Langevin
- 方程有 friction + random force
- canonical
- VACF 会受影响
- friction 太大会影响 diffusion
- 温度很稳定并不等于动力学没问题
😭之前只看 T(t) 感觉完全没问题
```

### 不理想的整理

```markdown
## Langevin 恒温器

Langevin 恒温器具有以下特点：

- 引入摩擦力；
- 引入随机力；
- 可以产生 canonical ensemble；
- 会影响 VACF；
- 可能影响扩散系数。

综上所述，在研究扩散性质时需要谨慎选择 Langevin 恒温器。
```

问题：信息没错多少，但原本最重要的“为什么”被压扁了，个人探索也消失了。

### 更合适的整理

```markdown
我一开始其实很容易被温度曲线骗过去：只要 $T(t)$ 很快贴着目标温度波动，看起来控温就已经“做得很好”了 😭。但如果我们真正想算的是扩散系数，判断标准就不能只停在温度上。

Langevin 动力学会在运动方程中显式加入摩擦项和随机力。它们可以帮助体系获得正确的热统计分布，但与此同时也直接参与了粒子的时间演化。于是，像 VACF 这样依赖速度时间相关性的量，自然可能对摩擦强度十分敏感；而扩散恰恰又是一个动力学问题。换句话说，“canonical sampling 正确”和“真实动力学不受扰动”本来就是两件不同的事。

这也解释了为什么只检查 $T(t)$ 远远不够。温度曲线很漂亮，最多说明控温这一层没有明显出问题；至于扩散系数是否已经被 thermostat 改变，还需要看摩擦参数、动力学相关函数以及最终输运量本身。
```

## 示例 2：文献不要按作者排队

### 原始笔记

```markdown
### Paper A
- 说 thermostat 影响 diffusion
- weak coupling 小很多

### Paper B
- NHC production MD
- 400 ps

### 我的结果
- NHC 比较慢
- CSVR 温度分布很好
- 但 VACF 看起来不一样

问题：文献里为什么大家还是用 NVT？
```

### 不理想

```markdown
## Paper A
……

## Paper B
……

## 我的结果
……

## 总结
……
```

### 更合适

```markdown
这里最让我困惑的地方其实不是“恒温器会不会影响动力学”——从方程本身看，这并不难理解——而是另一个更现实的问题：既然存在这种影响，为什么很多实际的生产 MD 仍然直接在 NVT 下跑很长时间？

不同文献在这里关注的层面并不完全一样。有些工作专门比较 thermostat 对 diffusion、viscosity 或时间相关函数的扰动，因此会把耦合强度本身当成研究对象；另一些材料模拟文章的目标则是得到某个温度下的扩散统计量，NVT 只是整个计算流程中的一个工具。后者使用 NHC 并不自动意味着“thermostat 对动力学绝对没有影响”，它更可能意味着：在作者采用的参数、体系尺寸和时间尺度下，这种影响被认为可以接受，或者至少没有成为文章的主要误差来源。

自己的测试反而很适合拿来理解这个区别。比如 CSVR 的温度分布可能相当漂亮，但如果 VACF 的形状发生了明显变化，就提醒我们不能只靠热力学采样质量评价输运计算。真正需要回答的是：这种变化最后会不会显著传递到 MSD 的长时间斜率和扩散系数上。
```

## 示例 3：技术细节处要“收紧”

### 原始笔记

```markdown
sigma_NE = ne^2 Z^2 D / kBT
Haven ratio 好像 0~1？
有人定义反过来
```

### 更合适

```markdown
如果从 tracer diffusion coefficient 出发，最直接得到的是 Nernst–Einstein 近似下的电导率。这里真正需要小心的反而不是公式本身，而是后面那个常被一句话带过的相关性修正。

不同文献对 Haven ratio / Haven factor 的符号和倒数关系并不总是统一。有的定义把真实电导率写成 Nernst–Einstein 电导率乘以一个小于 1 的因子，也有文献使用其倒数。因此，仅仅看到“$H$”或“$f$”不能直接假定它一定落在 $0$ 到 $1$ 之间；应先检查该文献给出的定义式，再比较数值。整理笔记时也最好把定义式和符号绑定在一起，避免后面跨论文比较时把两个互为倒数的量当成同一个东西。
```

关键：遇到定义冲突时，不为追求流畅而假装世界上只有一种约定。

## 示例 4：保留“我”的探索，但别变日记流水账

### 原始笔记

```markdown
今天看 alpha(t)
60-220 ps ~1
之前以为锯齿很多就是有问题
后来发现多时间原点统计会这样
还是不太懂 CI
```

### 更合适

```markdown
刚看到 MSD 曲线上的锯齿时，我第一反应其实是“这是不是模拟出了问题”。但把 $\alpha(t)$ 和多时间原点统计一起看以后，情况就没那么吓人了：在真正拿来拟合的时间区间里，$\alpha$ 如果已经稳定在 1 附近，至少说明这一段更接近正常扩散区，而不是仍停留在明显的 ballistic 或 anomalous regime。

这里也让我慢慢意识到，单独盯着一条“看起来够不够直”的 MSD 曲线很容易产生错觉。拟合窗口、时间原点数量和统计不确定度其实是同一个判断过程的不同侧面。至于 Bayesian 拟合给出的 credible interval 到底该怎么理解，则是下一步还需要单独理顺的问题。
```

这种写法保留了学习过程，但信息仍围绕科学问题推进。
